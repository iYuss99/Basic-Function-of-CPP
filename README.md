# Basic Function of C++

This repository contains practical exercises and implementations from the Algorithms & Programming Lab module on Basic Functions in C++.

## Topics Covered

* Function declaration and definition
* User-defined functions
* Library functions in C++
* Pass by value
* Pass by reference
* Pass by pointer
* Returning values and strings from functions
* Returning strings through pointers
* Function pointers
* Array of function pointers
* Callback functions
* The role of the main function in program execution

## Learning Objectives

The purpose of this repository is to understand the fundamental concepts of functions in C++ and their applications in program development. The exercises focus on code modularization, parameter passing techniques, function pointers, callback mechanisms, and the execution flow of C++ programs.

## Technologies

* C++
* GCC / MinGW Compiler
* Visual Studio Code
